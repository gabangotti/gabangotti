## EPITA — engineering and cybersecurity

I am completing EPITA's engineering programme, with graduation expected in
2027. After building foundations in algorithms, software engineering, Unix
systems and programming through intensive project-based learning, I joined the
**Systems, Networks and Security (SRS)** major.

The SRS major is a 900-hour specialization. My current coursework covers:

- offensive and defensive security for systems, networks and web applications;
- vulnerability exploitation, infrastructure hardening and advanced networks;
- Linux and Windows environments, Active Directory and containers;
- SOC/CERT operations, digital forensics and incident response.

### Selected core curriculum projects

- **42SH — POSIX shell (C):** implemented the core behaviour of a Unix shell.
- **Tiger compiler (C++):** worked on the implementation of a compiler for the

- **JWS — distributed backend (Java):** built a game backend based on multiple

- **OCR Sudoku solver (C):** led the student team and worked on digit

### Selected SRS projects

- **Multi-layer forensic challenge:** co-designed an incident investigation
  scenario connecting an AD CS certificate abuse, illegitimate VPN access and
  the compromise of a vulnerable diagnostic API. The investigation relies on
  log and PCAP correlation, API exploitation, command execution, network
  pivoting and analysis of Python persistence through a `.pth` file.
- **Resilience Copilot — cybersecurity hackathon:** contributed to an
  AI-assisted business continuity and disaster-recovery platform. The project
  combines continuous document ingestion, a dependency knowledge graph,
  incident-impact analysis and traceable LLM-assisted explanations, with a Go
  backend, React, PostgreSQL/pgvector and Docker.
- **myvrouter — userspace IPv4 router (C):** built a configurable router using
  raw sockets and `epoll`, with multiple network interfaces, an ARP table,
  ARP/ICMP handling, direct and static routing, and longest-prefix route
  selection.
- **Binary exploitation and reverse engineering:** analysed and patched x86
  crackmes, developed key generators, studied anti-debugging mechanisms and
  implemented a format-string exploit in C to redirect execution to shellcode.

I have also practised cybersecurity through **Hack The Box**, **Root-Me** and
the **DGSE Richelieu Challenge**.
